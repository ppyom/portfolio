# FormSection

`FormSection`은 폼 화면을 의미 단위로 구분하기 위한 섹션 컴포넌트입니다.

프로젝트, 프로필, 스킬 관리와 같은 관리자 페이지에서 입력 영역을 명확하게 분리하고 일관된 레이아웃을 제공합니다.

제목과 설명을 통해 섹션의 목적을 전달하며 내부 콘텐츠는 자유롭게 구성할 수 있습니다.

---

## 🚀 Usage

가장 기본적인 사용 예시입니다.

<Source
  code={`
import { FormSection } from '@/components/ui/form-section';

export const Example = () => (
    <FormSection title="프로젝트 기본 정보">
      <div>Content</div>
    </FormSection>
);
`}
  language="tsx"
/>

설명을 함께 표시할 수 있습니다.

<Source
  code={`
<FormSection
    title="프로젝트 기본 정보"
    description="프로젝트에 대한 기본 정보를 입력해주세요."
>
    <div>Content</div>
</FormSection>
`}
  language="tsx"
/>

섹션 내부에는 입력 필드, 업로드 컴포넌트, 정렬 가능한 리스트 등 다양한 UI를 배치할 수 있습니다.

<Source
  code={`
<FormSection
    title="주요 기능"
    description="프로젝트의 주요 기능을 작성해주세요."
>
    <DraggableList />
</FormSection>
`}
  language="tsx"
/>

## 📝 Technical Guidelines

### 🧠 Design Rules

- 입력 영역을 의미 단위로 구분
- 제목과 설명을 통한 정보 구조화
- 콘텐츠는 완전히 자유롭게 구성
- 관리자/사용자 페이지 모두 재사용 가능

### 🎨 Layout Rules

- 섹션 간 충분한 여백 유지
- 제목 -> 설명 -> 콘텐츠 순서 유지
- 카드 형태의 일관된 시각 구조 제공
- 콘텐츠 레이아웃은 상위 컴포넌트가 결정

### ♿ Accessibility

- 시맨틱 `section` 요소 사용
- 제목과 설명을 통한 맥락 제공
- 내부 폼 요소의 접근성 정책을 방해하지 않음

### 🛠 Implementation Details

- Compound Component 패턴 미사용
- 최소한의 API 제공
- children 기반 자유 구성
- 디자인 시스템 토큰 기반 스타일링
