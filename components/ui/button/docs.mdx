# Button

`Button` 컴포넌트는 사용자의 클릭 액션을 유도하는 핵심 인터랙션 요소입니다.
일관된 피드백과 명확한 시각적 위계를 제공하는 디자인 시스템의 기초가 됩니다.

## 🚀 Usage

가장 기본적인 사용 방법입니다. 필요한 `variant`와 `size`를 조합하여 사용하세요.

<Source
  code={`
import { Button } from '@/components/ui/button';

export const Example = () => (
  <Button variant="primary" size="md" onClick={() => {}}>
    Click Me
  </Button>
);
`}
  language="tsx"
/>

### Variants

서비스의 중요도에 따라 적절한 스타일을 선택합니다.

- **Secondary**: 보조 액션 (취소, 수정 등)
- **Ghost**: 배경색 없이 텍스트나 아이콘만 강조할 때 (더보기, 닫기 등)

## 📝 Technical Guidelines

### 🧠 Design Rules

- **UI Primitive**: 버튼은 원자(Atomic) 단위 컴포넌트이므로 외부 여백(margin)을 직접 가지지 않습니다.
- **State Persistence**: `isLoading` 상태에서도 버튼의 `children`은 항상 유지되어 레이아웃 시프트를 방지합니다.

### ♿ Accessibility

- `disabled` 속성은 실제 인터랙션을 차단하고 시각적으로 비활성화 상태임을 알립니다.
- `aria-busy`를 통해 로딩 상태를 스크린리더에 전달합니다.
- 내부 스피너 아이콘은 `aria-hidden="true"` 처리를 권장합니다.

### 🛠 Implementation Details

- **Compound Class**: `isLoading` 상태일 때 `gap-2`를 동적으로 추가하여 스피너와 텍스트 사이의 간격을 확보합니다.
- **Strict Disabled**: 로딩 중일 때는 자동으로 `disabled` 상태가 활성화되어 중복 클릭을 방지합니다.

### 💡 Tips

- 버튼 내부에 텍스트 없이 아이콘만 사용하는 경우, 반드시 `aria-label`을 통해 버튼의 목적을 명시해야 합니다.
- `variant="ghost"`는 주로 배경과 대비가 적은 영역이나, 리스트 내의 보조 액션에 사용합니다.
