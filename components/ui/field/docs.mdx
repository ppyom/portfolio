# Field

`Field` 컴포넌트는 폼 관련 UI Primitive를 구조적으로 조합하기 위한 레이아웃 래퍼입니다.
입력 요소와 라벨, 설명, 상태 피드백을 하나의 그룹으로 묶어 일관된 폼 구조를 제공합니다.

`group`과 `data-*` 속성을 기반으로 상태를 전달하여, 하위 컴포넌트 간 느슨한 결합을 유지하면서도 시각적 일관성을 보장합니다.

## 🚀 Usage

기본적인 조합 예시입니다.

<Source
  code={`
import { Field } from '@/components/ui/field';
import { Label } from '@/components/ui/label';
import { Input } from '@/components/ui/input';
import { Description } from '@/components/ui/description';
import { ErrorMessage } from '@/components/ui/error-message';

export const Example = () => (
  <Field invalid>
      <Label
        required
        htmlFor="email"
      >
        이메일
      </Label>

      <Description>
        회사 이메일을 입력해주세요.
      </Description>

      <Input
        id="email"
        variant="error"
        placeholder="이메일을 입력해주세요"
      />

      <ErrorMessage>
        올바른 이메일 형식이 아닙니다.
      </ErrorMessage>

  </Field>

);
`}
language="tsx"
/>

상태 전달도 함께 사용할 수 있습니다.

<Source
  code={`

  <Input

  />
</Field>
`}
  language="tsx"

## 📝 Technical Guidelines

### 🧠 Design Rules

- **Composition First**: 단독 UI가 아닌 Primitive 조합을 위한 구조적 래퍼입니다.
- **Loose Coupling**: Context 없이 `group` 기반 상태 전달만 담당합니다.
- **Consistent Spacing**: 기본 `gap`을 통해 필드 간 일정한 간격을 유지합니다.
- **Supporting Text Layer**: Description, ErrorMessage와 함께 입력 보조 피드백 구조를 완성합니다.

### ♿ Accessibility

- **Semantic Structure**: `Label`과 Form Control의 연결을 권장합니다.
- **State Reflection**: `disabled`, `invalid`, `required` 상태를 하위 UI에 전달할 수 있습니다.
- **Composable Feedback**: Description / ErrorMessage와 조합하여 명확한 안내 및 오류 피드백을 제공할 수 있습니다.

### 🛠 Implementation Details

- **State Propagation**: `data-disabled`, `data-invalid`, `data-required`
- **Tailwind Integration**: `group-data-*` selector 기반 스타일링
- **Optional Wrapper**: Primitive는 독립 사용 가능하며, Field는 선택적 조합 레이어입니다.
