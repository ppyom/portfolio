# Avatar

`Avatar`는 사용자 및 작성자 정보를 시각적으로 표현하기 위한 프로필 이미지 컴포넌트입니다.

이미지가 정상적으로 로드되면 프로필 이미지를 표시하고 로드에 실패하거나 이미지가 없을 경우 fallback 텍스트를 렌더링합니다.

단일 props 기반 API로 설계되어 간단하고 직관적인 사용성을 제공합니다.

## 🚀 Usage

기본적인 사용 예시입니다.

<Source
  code={`
import { Avatar } from '@/components/ui/avatar';

export const Example = () => (
    <Avatar
      src="https://github.com/ppyom.png"
      alt="이예진"
      fallback="예"
      size="md"
    />
);
`}
  language="tsx"
/>

이미지가 없거나 로드에 실패하면 fallback이 표시됩니다.

<Source
  code={`
<Avatar
    fallback="예"
    size="md"
/>
`}
  language="tsx"
/>

## 📝 Technical Guidelines

### 🧠 Design Rules

- **Simple API**: props 기반 단일 컴포넌트 구조
- **Graceful Fallback**: 이미지 실패 시 자동 대체 UI
- **Consistent Surface**: 크기별 일관된 시각 구조
- **Minimal Primitive**: 필요한 기능만 제공

### ♿ Accessibility

- `alt` 속성 지원
- fallback 상태에서도 `aria-label` 유지
- decorative image가 아닐 경우 대체 텍스트 제공

### 🛠 Implementation Details

- `onError` 기반 fallback 처리
- `cva` size variant 관리
- `object-cover` 비율 유지
- 내부 state 기반 이미지 오류 감지
