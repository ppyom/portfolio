# Input

`Input` 컴포넌트는 사용자의 텍스트 데이터를 수집하기 위한 가장 기본적인 필드 요소입니다.
디자인 시스템의 타이포그래피 및 색상 토큰을 준수하며, 다양한 상태 피드백을 통해 직관적인 입력 경험을 제공합니다.

## 🚀 Usage

가장 기본적인 제어 컴포넌트 형식의 사용 예시입니다.

<Source
  code={`
import { Input } from '@/components/ui/input';

export const Example = () => (
  <Input
    placeholder="이메일을 입력해주세요"
    size="md"
    onChange={(e) => console.log(e.target.value)}
  />
);
`}
  language="tsx"
/>

## 📝 Technical Guidelines

### 🧠 Design Rules

- **UI Primitive**: 인풋 컴포넌트는 외부 레이아웃에 영향을 주지 않도록 자체적인 외부 여백(margin)을 가지지 않습니다.
- **Visual Consistency**: `Error` 상태일 때 레이아웃이 흔들리지 않도록 보더 두께를 고정하고 색상만 변경하는 것을 권장합니다.

### ♿ Accessibility

- **Labeling**: 가급적 부모 컴포넌트에서 `<label>`과 `htmlFor`를 연결하여 입력 목적을 명확히 해야 합니다.
- **Error Feedback**: `error` 상태일 경우 `aria-invalid="true"` 속성을 자동 부여하여 스크린 리더가 오류를 인지할 수 있게 합니다.
- **Placeholder**: 플레이스홀더는 레이블을 대체할 수 없으므로, 중요한 정보는 항상 별도 텍스트로 노출해야 합니다.

### 🛠 Implementation Details

- **Focus Ring**: 키보드 접근성을 위해 `focus-visible` 시 명확한 아웃라인 피드백을 제공합니다.
- **Form Integration**: `React Hook Form` 등 외부 라이브러리와의 연동을 위해 `ref` 전달(Forwarding)이 완벽히 지원됩니다.
