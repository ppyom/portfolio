# Input

`Input` 컴포넌트는 사용자의 텍스트 데이터를 수집하기 위한 가장 기본적인 필드 요소입니다.
디자인 시스템의 타이포그래피 및 색상 토큰을 준수하며, 다양한 상태 피드백을 통해 직관적인 입력 경험을 제공합니다.

## 🚀 Usage

가장 기본적인 사용 예시입니다. 필요한 `variant`와 `size`를 조합하여 사용하세요.

<Source
  code={`
import { Input } from '@/components/ui/input';

export const Example = () => (
  <Input
    placeholder="이메일을 입력해주세요"
    variant="default"
    size="md"
  />
);
`}
  language="tsx"
/>

## 📝 Technical Guidelines

### 🧠 Design Rules

- **UI Primitive**: 인풋 컴포넌트는 외부 레이아웃에 영향을 주지 않도록 자체적인 외부 여백(margin)을 가지지 않습니다.
- **Visual Consistency**: `Error` 상태일 때 레이아웃이 흔들리지 않도록 보더 두께를 고정하고 색상만 변경하는 것을 권장합니다.

### ♿ Accessibility

- **Labeling**: 가급적 부모 컴포넌트에서 `<label>`과 연결하여 입력 목적을 명확히 해야 합니다.
- **Keyboard**: 키보드 접근성을 위해 `focus-visible` 시 명확한 아웃라인 피드백을 제공합니다.

### 🛠 Implementation Details

- **Form Integration**: `React Hook Form` 등 외부 라이브러리와의 연동을 위해 `ref` 전달(Forwarding)이 완벽히 지원됩니다.
- **Attribute Inheritance**: 기본 HTML `input` 요소의 속성들을 그대로 상속받아 유연하게 확장 가능합니다.
