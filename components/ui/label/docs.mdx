# Label

`Label` 컴포넌트는 입력 필드의 목적을 명확하게 전달하기 위한 텍스트 요소입니다.
폼 컨트롤과 연결되어 접근성을 향상시키며, 필수 입력 여부와 비활성 상태를 시각적으로 표현할 수 있습니다.

## 🚀 Usage

가장 기본적인 라벨 사용 예시입니다.

<Source
  code={`
import { Label } from '@/components/ui/label';

export const Example = () => (
  <Label htmlFor="email">
    이메일
  </Label>
);
`}
  language="tsx"
/>

필수 입력 필드를 표시할 수도 있습니다.

<Source
  code={`
<Label htmlFor="email" required>
  이메일
</Label>
`}
  language="tsx"
/>

## 📝 Technical Guidelines

### 🧠 Design Rules

- **Semantic First**: 반드시 폼 컨트롤과 연결되는 의미적 라벨로 사용하는 것을 권장합니다.
- **Required Indicator**: 필수 표시(`*`)는 시각적 보조 요소이며, 실제 검증 책임은 폼 로직이 담당해야 합니다.
- **Layout Independence**: 외부 레이아웃에 영향을 주지 않도록 margin을 포함하지 않습니다.

### ♿ Accessibility

- **htmlFor 연결**: 대응되는 입력 요소의 `id`와 연결해 스크린 리더가 올바르게 인식할 수 있도록 합니다.
- **Required Mark**: 별표(`*`)는 `aria-hidden="true"` 처리되어 보조기기에 불필요하게 중복 전달되지 않습니다.
- **Disabled State**: 상위 `group` 상태를 통해 비활성 시각 피드백을 제공합니다.

### 🛠 Implementation Details

- **Group Integration**: `data-disabled` 상태를 가진 상위 `group`과 함께 사용할 수 있습니다.
- **Standalone Usage**: 독립적으로도 사용 가능하며 특정 필드 구조에 강하게 결합되지 않습니다.
- **Styling Consistency**: 디자인 토큰 기반 타이포그래피와 상태 컬러를 따릅니다.
