# ImageUpload

`ImageUpload`는 이미지 업로드와 미리보기를 관리하는 파일 업로드 컴포넌트입니다.

기존 업로드된 이미지와 새로 추가된 이미지를 동일한 구조로 관리하며 단일 및 다중 업로드를 지원합니다.

프로젝트 썸네일 업로드, 시연 이미지 등록, CMS 편집 화면과 같은 관리자 인터페이스에 최적화되어 있습니다.

## 🚀 Usage

기본적인 사용 예시입니다.

<Source
  code={`
import { Button } from '@/components/ui/button';
import {
    ImageUpload,
    ImageUploadTrigger,
    ImageUploadPreview,
} from '@/components/ui/image-upload';

export const Example = () => (
    <ImageUpload>
      <ImageUploadTrigger>
        <Button>이미지 업로드</Button>
      </ImageUploadTrigger>
      <ImageUploadPreview />
    </ImageUpload>
);
`}
  language="tsx"
/>

다중 업로드도 지원합니다.

<Source
  code={`
<ImageUpload multiple>
    <ImageUploadTrigger>
      <Button>이미지 업로드</Button>
    </ImageUploadTrigger>
    <ImageUploadPreview />
  </ImageUpload>
`}
  language="tsx"
/>

기존 업로드된 이미지도 초기값으로 설정할 수 있습니다.

<Source
  code={`
<ImageUpload
    multiple
    defaultFiles={[
      {
        id: '1',
        url: '/project-thumbnail.png',
      },
    ]}
>
    <ImageUploadTrigger>
      <Button>이미지 업로드</Button>
    </ImageUploadTrigger>
    <ImageUploadPreview />
</ImageUpload>
`}
  language="tsx"
/>

## 📝 Technical Guidelines

### 🧠 Design Rules

- **Compound Composition**: Trigger / Preview 기반 조합 구조
- **Headless Trigger**: Trigger UI를 소비자가 자유롭게 구성
- **Single Source of Truth**: Context 기반 상태 관리
- **Unified File Model**: remote / local 파일 통합 관리
- **Minimal API Surface**: 핵심 업로드 흐름 중심 설계

### ♿ Accessibility

- native file input 기반 업로드
- `button` 기반 명확한 삭제 액션 제공
- `disabled` 상태 시 전체 상호작용 차단

### 🛠 Implementation Details

- Context 기반 상태 공유
- `URL.createObjectURL` 미리보기 생성
- `URL.revokeObjectURL` 메모리 정리
- remote / local 상태 구분 관리
- disabled 상태 전파 처리
