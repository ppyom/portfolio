# Badge

`Badge` 컴포넌트는 상태, 분류, 메타 정보를 시각적으로 구분하기 위한 UI Primitive입니다.

간단한 상태 표시부터 CMS 관리 화면의 콘텐츠 상태 구분까지 다양한 상황에서 사용할 수 있습니다.

variant와 size 조합을 통해 의미와 강조 수준을 명확하게 전달할 수 있습니다.

## 🚀 Usage

기본적인 사용 예시입니다.

<Source
  code={`
import { Badge } from '@/components/ui/badge';

export const Example = () => (
    <>
      <Badge>Primary</Badge>
      <Badge variant="success">Published</Badge>
      <Badge variant="warning">Draft</Badge>
      <Badge variant="error">Archived</Badge>
    </>
);
`}
  language="tsx"
/>

size를 함께 사용할 수 있습니다.

<Source
  code={`
<Badge size="sm">Small</Badge>
<Badge size="md">Medium</Badge>
<Badge size="lg">Large</Badge>
`}
  language="tsx"
/>

### Variants

의미 전달을 위한 다양한 상태 variant를 제공합니다.

- **Primary**: 기본 강조
- **Secondary**: 보조 정보
- **Info**: 정보성 상태
- **Success**: 완료 / 게시 상태
- **Warning**: 주의 / 임시 상태
- **Error**: 오류 / 비활성 상태
- **Muted**: 보관 / 약한 강조

Badge 크기 조절을 지원합니다.

- **sm**: 테이블 / compact UI

## 📝 Technical Guidelines

### 🧠 Design Rules

- **Semantic Variant**: 의미 기반 상태 표현
- **Compact UI**: 최소 공간으로 정보 전달
- **Consistent Scale**: size별 균형 유지
- **Composable**: 다른 Primitive와 자연스럽게 결합

### ♿ Accessibility

- **Semantic Content**: 상태 의미를 텍스트로 함께 전달하는 것을 권장합니다
- **Readable Contrast**: 모든 variant는 충분한 대비를 유지해야 합니다
- **Non-interactive Primitive**: 상태 표시 용도로 사용합니다
