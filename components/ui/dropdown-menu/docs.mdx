# DropdownMenu

`DropdownMenu`는 사용자 액션을 컨텍스트 기반으로 그룹화하여 표시하는 메뉴 컴포넌트입니다.

버튼 클릭을 기준으로 메뉴를 열고 닫을 수 있으며 `DropdownItem`, `DropdownSeparator`와 조합하여 다양한 액션 메뉴를 구성할 수 있습니다.

포탈 없이 Trigger를 기준으로 위치를 계산하며 간단한 CMS 액션 메뉴 패턴에 최적화되어 있습니다.

## 🚀 Usage

기본적인 사용 예시입니다.

<Source
  code={`
import {
    DropdownMenu,
    DropdownTrigger,
    DropdownContent,
    DropdownItem,
    DropdownSeparator,
} from '@/components/ui/dropdown-menu';
import { Button } from "@/components/ui/button";

export const Example = () => (
    <DropdownMenu>
      <DropdownTrigger>
        <Button>메뉴 열기</Button>
      </DropdownTrigger>
      <DropdownContent>
        <DropdownItem>수정</DropdownItem>
        <DropdownItem>복제</DropdownItem>
        <DropdownSeparator />
        <DropdownItem variant="destructive">
          삭제
        </DropdownItem>
      </DropdownContent>
    </DropdownMenu>
);
`}
  language="tsx"
/>

Controlled 상태도 지원합니다.

<Source
  code={`
const [open, setOpen] = useState(false);

<DropdownMenu
    open={open}
    onOpenChange={setOpen}
>
    ...
</DropdownMenu>
`}
  language="tsx"
/>

## 📝 Technical Guidelines

### 🧠 Design Rules

- **Composition First**: Trigger / Content / Item 조합 중심 구조
- **Controlled / Uncontrolled**: 외부 상태 제어 및 내부 상태 관리 모두 지원
- **Minimal Surface API**: 필요한 Primitive만 노출
- **Action Focused**: 단순 액션 선택 UX에 최적화

### ♿ Accessibility

- `role="menu"` 제공
- Escape 키 닫기 지원
- 외부 클릭 dismiss 지원

### 🛠 Implementation Details

- Context 기반 상태 공유
- `cloneElement` Trigger 확장
- `cva` variant 관리
- Trigger 기준 상대 위치 계산
